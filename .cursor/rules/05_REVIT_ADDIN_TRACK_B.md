# 05 — Revit Add-in (Track B only: Revit 2025, 2026, 2027)

**Build this only if ADR-001 chose Track B.** If Track A was chosen, skip this file and state so in the final report.

## Project structure
```
src/RevitAddin/
  RevitAddin.csproj            # Configurations R25;R26;R27, TargetFramework by config, UseWPF
  App.cs                       # IExternalApplication
  Commands/EditFileInfoCommand.cs   # IExternalCommand
```

## App behaviour
- **Ribbon:** tab "File Info" (or add to an existing tab if configured) → panel "Metadata" → button "Edit File Info" (command below). Icons 16/32 px.
- **Events (register in `OnStartup`, unregister in `OnShutdown`):**
  - `ControlledApplication.DocumentOpened`
  - `ControlledApplication.DocumentSaved`
  - `ControlledApplication.DocumentSavedAs`
  - `ControlledApplication.DocumentSynchronizedWithCentral`
  Ignore family docs, linked docs, and documents without a file path.
- **No API calls on background threads.** If the file store write must be deferred (file still locked), queue it and retry using an `ExternalEvent` + short timer (max 3 retries), then show a non-blocking `TaskDialog` once and log.

## Model storage (Project Information shared parameters)
- Create via `Application.OpenSharedParameterFile` using a **temporary** shared-parameter file generated by the add-in (never touch the user's shared param file); **fixed GUIDs** per parameter (commit in code).
- Names: `RvtFileInfo_Discipline`, `RvtFileInfo_Location`, `RvtFileInfo_Originator`, `RvtFileInfo_SubDiscipline`, `RvtFileInfo_DocumentType`, `RvtFileInfo_Program`, `RvtFileInfo_SubProgram`, plus hidden `RvtFileInfo_ModifiedUtc`.
- Data type: `SpecTypeId.String.Text` (via `ExternalDefinitionCreationOptions`), instance binding to `BuiltInCategory.OST_ProjectInformation`, group `GroupTypeId.IdentityData` (verify ForgeTypeId group API for 2025–2027; `BuiltInParameterGroup` is gone in recent versions).
- All parameter creation/binding and value changes inside one named `Transaction` ("RvtFileInfo: update"). Handle read-only/workshared elements: if Project Information is owned by another user, show the owner and skip.
- Display labels in the dialog must be exactly: Discipline, Location, Originator, Sub Discipline, Document Type, Program, Sub Program.

## Command: `EditFileInfoCommand`
- `[Transaction(TransactionMode.Manual)]`, available in project documents only (`IExternalCommandAvailability`).
- Opens WPF dialog (modal, owner = Revit main window), loads current values, validates (≤256 chars, trimmed), writes parameters in a transaction, then calls `FileStoreSync` if the document has a path (otherwise queue for first save).
- Optional `picklists.json` (`%ProgramData%\RvtFileInfo\picklists.json`) → editable `ComboBox` with free text allowed.

## Deployment manifest (`.addin`)
One manifest per Revit year, installed to `%ProgramData%\Autodesk\Revit\Addins\<year>\RvtFileInfo.addin`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<RevitAddIns>
  <AddIn Type="Application">
    <Name>RvtFileInfo</Name>
    <Assembly>C:\Program Files\RvtFileInfo\RevitAddin\2025\RvtFileInfo.RevitAddin.dll</Assembly>
    <AddInId>{NEW-GUID}</AddInId>
    <FullClassName>RvtFileInfo.RevitAddin.App</FullClassName>
    <VendorId>RFI</VendorId>
    <VendorDescription>RvtFileInfo</VendorDescription>
  </AddIn>
</RevitAddIns>
```
- Assemblies per year under `...\RevitAddin\2025|2026|2027\`. Use a **different AddInId per year only if required**; otherwise one GUID is fine across years.
- Installer writes a manifest **only for Revit versions detected** (registry `HKLM\SOFTWARE\Autodesk\Revit\...` or presence of `%ProgramFiles%\Autodesk\Revit 20xx`), but also supports `INSTALLALLYEARS=1`.
- Load isolation: Revit 2025+ loads add-ins in its own `AssemblyLoadContext`; keep third-party dependencies minimal and avoid conflicting versions (e.g. do not ship Newtonsoft.Json — use `System.Text.Json`).

## Native interop with the store
- `Store.Core` exposes a flat C ABI (`rfi_read`, `rfi_write`, UTF-16 in/out). `Store.Net` P/Invokes it. Ship `RvtFileInfo.Store.dll` (x64) in `%ProgramFiles%\RvtFileInfo\`; load by full path with `NativeLibrary.SetDllImportResolver`.

## Testing without full Revit automation
- Unit-test `ProjectInfoParameters` and sync decision logic against interfaces (`IProjectInfoAccessor`).
- Manual test script in file 07 for each Revit year installed.
- If Revit is not installed on the build machine: build all three configs, run unit tests, and state "not run inside Revit" explicitly in the final report.

## Done when
- Add-in loads in Revit 2025, 2026 and 2027 with no manifest errors and no "unsigned add-in" regressions beyond the standard first-load prompt.
- Edit → Save → Explorer shows the new values; Save As → new file has values; Sync with Central → local file has values.
